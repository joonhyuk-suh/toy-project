# 커뮤니티 후기 노출

## Decisions

- 커뮤니티에는 이 앱 사용자가 공개를 허용한 후기만 보여 준다. 외부 커뮤니티 후기를 가져오거나 예시 후기를 섞지 않는다.
- 공개하지 않은 후기는 작성자 본인에게만 보이고 평균과 개수에도 들어가지 않는다.
- 커뮤니티는 조회만 한다. 댓글, 토론, 지인 추천은 두지 않는다.

## Boundaries

- 후기의 구성, 작성 자격, 수정, 공개 여부 선택, 평가 척도는 이 결정이 정하지 않는다. 취향 아카이브 스펙이 정한다.

## Why

사용자 결정. 앱 안에서 쌓이는 후기가 성공 신호이고 다음 추천의 근거가 되어야 한다. `PRODUCT.md`가 커뮤니티를 공개 후기 조회로 한정했다.

## Reconsider when

- 공개 후기가 오래 비어 있어 후기 확인 단계가 계속 막힐 때

## Still-rejected alternatives

- 외부 커뮤니티 후기 링크, 예시 후기 — 앱 안의 평가가 성공 신호라서 섞으면 그 신호가 흐려진다. 위 조건이 생길 때 다시 본다.
