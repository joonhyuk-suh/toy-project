# 판매점 데이터 출처

## Decisions

- 판매점은 카카오 로컬 API 키워드 검색으로 찾고, 카카오맵 JavaScript SDK 지도 위에 핀으로 보여 준다.
- 이 서비스는 주요 브랜드 목록을 DB에 두고 관리한다. 주요 브랜드 이름으로 검색된 장소는 카카오 카테고리와 상관없이 모두 판매점으로 보여 준다.
- 주요 브랜드에 없더라도 카카오에 향수 카테고리로 등록된 장소는 판매점으로 보여 준다. 이런 판매점은 판매 제품을 모른다고 표시한다.
- 판매점의 판매 제품은 브랜드까지만 말한다. 특정 향수의 재고는 주장하지 않는다.
- 카카오 REST API 키는 서버에서만 쓴다.

## Boundaries

- 매장을 직접 조사해 저장하거나 매장별 재고를 관리하지 않는다.
- 주요 브랜드 목록을 편집하는 관리 화면은 이 결정에 들어 있지 않다.

## Why

한국 향수 매장과 판매 제품을 주는 공개 데이터가 없다(2026-11-19 확인). Scento 데이터에도 판매처가 없다. 사용자가 직접 정리한 매장 목록 대신 카카오 장소 검색을 골랐고, 브랜드 이름으로 찾은 장소는 카테고리가 향수가 아니어도(예: 백화점 안 브랜드 매장) 모두 보여 달라고 했다. 브랜드 이름으로 찾았다는 사실이 "이 브랜드 매장"이라고 말할 수 있는 유일한 근거라서 재고까지는 말하지 않는다.

## Reconsider when

- 카카오 로컬 API의 무료 쿼터나 약관이 서비스 사용량에 맞지 않게 바뀔 때
- 매장별 판매 제품을 주는 공개 데이터나 제휴처가 생길 때

## Still-rejected alternatives

- 직접 정리한 매장 목록 — 매장이 바뀔 때마다 사람이 고쳐야 한다. 카카오 검색이 브랜드 매장을 제대로 찾지 못한다는 근거가 쌓일 때 다시 본다.
- 향수 카테고리 장소만 보여 주기 — 백화점 안 브랜드 매장처럼 카테고리가 다른 곳이 빠진다.

## Evidence worth preserving

- 카카오 로컬 API는 `GET https://dapi.kakao.com/v2/local/search/keyword.json`에 `Authorization: KakaoAK {REST_API_KEY}`로 호출하고, `x`, `y`, `radius`로 지역을 좁힌다. 응답에 장소 이름, 카테고리 이름, 주소, 전화, 카카오맵 장소 링크, 좌표가 있고 판매 제품은 없다(2026-11-19 공식 문서 확인, 키로 직접 호출하지는 않음).
