# 시각 정체성

## Decisions

- 글꼴은 역할로 나눈다. 제목은 명조(세리프), 본문과 UI 문구는 고딕(산세리프), 향수 이름 같은 영문 고유명은 이탤릭 세리프로 쓴다. 웹폰트 기준은 제목 아리따 부리 계열, 본문 Pretendard 계열이다.
- 고정폭 글꼴을 화면 전체에 적용하지 않는다. 현재 shadcn 프리셋의 전체 `font-mono` 적용과 JetBrains Mono는 이 결정으로 대체한다.
- 색은 따뜻한 아이보리·베이지 바탕, 종이 같은 밝은 카드, 짙은 갈색 강조색으로 구성한다. 현재 프리셋의 파란 `primary`는 이 결정으로 대체한다.
- 토큰 이름은 shadcn semantic token(`background`, `foreground`, `card`, `primary`, `secondary`, `muted`, `border` 등)을 그대로 두고 값만 바꾼다.
- 향 계열 12개(시트러스, 과일, 그린·차, 꽃, 하얀 꽃, 파우더리, 살냄새, 달콤함, 앰버, 스파이스, 스모키, 우디)는 계열마다 채도를 낮춘 자연색 하나를 갖는다. 계열을 나타내는 배지, 아이콘 바탕, 향수병 층, 차트는 모두 이 계열 색을 쓴다.
- 아이콘은 프로젝트 의존성인 lucide의 얇은 선 아이콘을 쓰고, 필요하면 계열 색 원 위에 올린다. 이모지를 아이콘이나 이미지 대신 쓰지 않는다.
- 레이아웃은 PC 화면을 기본으로 하는 반응형이다. 넓은 화면(1000px 이상)은 상단 메뉴와 2–3열, 중간(640–1000px)은 열을 줄인 배치, 좁은 화면(640px 미만)은 1열과 하단 탭 메뉴를 쓴다.

## Boundaries

- 일반 UI를 shadcn component로 구성한다는 [ui-composition](ui-composition.md)은 그대로 유지한다. 이 계약은 그 component에 입힐 글꼴, 색, 아이콘의 값과 쓰임만 정한다.
- 향 계열 색은 계열을 나타낼 때만 쓴다. 버튼, 오류, 성공 같은 일반 상태 표현은 semantic token을 쓴다.
- 구체적인 화면 구성은 각 작업 단위의 승인된 프로토타입이 정한다. 첫 기준 화면은 `docs/specs/scent-finder/prototype.html`이다.

## Why

향수·뷰티 분야 사용자는 화면의 인상으로 서비스의 품질을 판단한다. 기존 프리셋의 고정폭 글꼴, 파란 강조색, 이모지 아이콘은 사용자가 직접 거부했다. 향수 브랜드 웹사이트(Byredo, Le Labo, Diptyque)는 절제된 여백, 차분한 색, 글자를 이미지처럼 쓰는 방식으로 고급스러움을 만들고, 뷰티 브랜드는 제목 세리프와 본문 산세리프를 나누는 경우가 많다. 토큰 이름을 유지하면 shadcn component를 그대로 쓰면서 값만 바꿀 수 있다.

## Reconsider when

- 실제 사용자 평가나 사용성 확인에서 명조 제목이 읽기 어렵다는 근거가 반복될 때
- 아리따 부리나 Pretendard의 라이선스나 배포 조건이 서비스에 맞지 않게 바뀔 때

## Still-rejected alternatives

- 현재 shadcn 프리셋(전체 고정폭 글꼴, 파란 강조색)을 그대로 쓰는 방식 — 향수 서비스의 인상과 맞지 않아 사용자가 거부했다. 서비스 분야가 바뀔 때만 다시 본다.
- 이모지를 음식·재료 아이콘으로 쓰는 방식 — 플랫폼마다 모양이 달라지고 가벼워 보여 사용자가 거부했다.
- 휴대폰 화면만 최적화한 레이아웃 — 웹서비스로 제공하므로 PC가 기본이다.
